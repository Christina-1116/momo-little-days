# MOMO · 毛毛的小日子

> 一点点快乐，每一天。A little joy, every day.

**在线试玩：<https://christina-1116.github.io/momo-little-days/>**（建议用手机打开）

一款温暖复古风的**毛绒 3D 小兔养成小游戏**（移动端网页）。把养成、任务闯关、家园装扮、相册纪念串成一个完整的小循环：

**照顾毛毛 → 获得精力去冒险 → 赚金币和奖励 → 装扮自己和小窝 → 每一个时刻都被收进相册**

所有画面（毛绒兔子、装扮、家具、地图、场景）都由 SVG 手绘生成，音效与八音盒音乐由 WebAudio 实时合成，**没有任何图片 / 音频素材文件**，纯 HTML + CSS + JS，无需构建。

## 玩法

| 模块 | 内容 |
| --- | --- |
| 🏠 **首页 · 养成** | 饱腹 / 心情 / 精力 / 清洁四项数值随真实时间变化；点一点、**搓一搓**毛毛会撒娇；把食物**拖到嘴边**喂食；洗澡时**用手指戳破泡泡**；哄睡后场景变成夜晚，精力恢复 |
| ✅ **每日任务** | 6 个每日小任务 + 每日宝箱 + 每日小礼物，跨天自动重置 |
| 🐾 **小小冒险** | 雏菊草地 → 蘑菇森林 → 星光池塘，3 个区域 9 个关卡，每关 1~3 星，首通解锁限定奖励 |
| 🎮 **三个小游戏** | **萝卜雨**（拖动接零食、躲石头、连击加分）· **拔萝卜**（打地鼠式，别碰蜜蜂）· **记忆翻翻乐**（翻牌配对） |
| 👗 **小小衣橱** | 帽饰 / 围巾 / 小物共 17 件，可先试穿再购买，实时穿戴在兔子身上 |
| 🛋️ **毛毛的小窝** | 座椅、地毯、灯、绿植、墙饰、墙纸、窗景 7 类家具可试摆再购买；房间里的东西都能点：开关灯、唱片机放音乐、给植物浇水、让毛毛跳上沙发… |
| 📷 **回忆相册** | 12 个里程碑 / 冒险回忆随成长解锁，随时按相机拍一张拍立得合照，可收藏 |

进度自动保存在浏览器本地（localStorage）。

## 本地运行

在项目根目录执行：

```bash
python3 -m http.server 5173
```

然后打开 <http://localhost:5173>。桌面端会显示手机框预览，手机上打开即为全屏。

## 目录

```
index.html        页面骨架
css/style.css     全部样式与动效
js/art.js         SVG 美术：毛绒兔子、装扮、家具、场景、冒险地图
js/data.js        数据：装扮、家具、食物、关卡、回忆、任务、台词
js/audio.js       WebAudio 音效与八音盒背景音乐
js/games.js       三个小游戏
js/app.js         主逻辑：养成数值、页面路由、交互、存档
```
